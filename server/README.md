# 本地 Minecraft Java 测试服

机器人不是服务器。本工程不包含 Minecraft 商业服务端、客户端、账号或模型密钥。

使用你已有的 Minecraft Java **1.16.5** 本地测试服务器，或自行安装对应官方服务端。
官方服务端入口：https://www.minecraft.net/en-us/download/server
官方版本元数据：https://piston-meta.mojang.com/mc/game/version_manifest_v2.json

1. 使用与服务端匹配的 Java 运行时。Java 1.16.5 的旧服务端应使用它支持的 Java 版本；不要默认所有现代 Java 都兼容。
2. 在一个新建的测试世界目录启动服务端，按服务端提示自行阅读并决定是否接受其 EULA。本工程不自动接受协议。
3. 停服后参考 `server.properties.example` 配置，再重启。`online-mode=false` 只能用于你有权限的本地/隔离测试环境；示例明确绑定 `127.0.0.1`。
4. 用你自己的同版本 Java 客户端连接 `127.0.0.1:25565`。先确认出生点附近有普通橡树/白桦等原木和可站立的平地。
5. 机器人没有 op，不用传送、给予物品或修改世界命令。第一次学习用和平生存模式，避免战斗干扰理解代码。
6. 测试时不要站在机器人、掉落物或放置点上，也不要抢拾取掉落物；实体竞争会让库存验证失败，这是预期防护。

要查看画面：正常客户端加入同一个服务器即可看到名为 `JevStudent` 的玩家走路、挖木头和放置工作台。
如果服务器启用正版认证，将工程根目录 `.env` 中 `MC_AUTH` 改成 `microsoft`，按认证流程登录自己的机器人账号；不要把密码写入代码。

## 已有服务端的最短路径

修改工程 `.env` 的 `MC_HOST`、`MC_PORT`、`MC_VERSION`，确保和服务端一致。
本示例默认围绕 1.16.5 的物品和交互编写，没有针对其他游戏版本进行实机验证。
